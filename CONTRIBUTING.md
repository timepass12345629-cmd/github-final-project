# Contributing to Simple Interest Calculator

Thank you for your interest in contributing to the Simple Interest Calculator project!

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

---

## How to Contribute

### 1. Reporting Bugs
- If you find a bug or unexpected behavior, please check existing issues to ensure it has not already been reported.
- If it hasn't been reported, open a new issue with a descriptive title and steps to reproduce.

### 2. Suggesting Enhancements
- Enhancement requests and new ideas are encouraged!
- Open an issue describing your proposed feature and how it benefits the calculator.

### 3. Submitting Pull Requests
1. Fork the repository.
2. Create a new topic branch (`git checkout -b feature/your-feature-name`).
3. Make your changes and write clear, concise commit messages.
4. Ensure the web application (`index.html`) and bash script (`simple-interest.sh`) function as expected.
5. Push to your branch and open a Pull Request against `main`.

---

## Code of Conduct

Please note that this project is released with a [Contributor Code of Conduct](CODE_OF_CONDUCT.md). By participating in this project you agree to abide by its terms.
